About

I'm a final-year Computer Science student at NUST SEECS working on security for LLM and RAG systems, adversarial ML, and the tooling needed to actually ship it. My work sits at the intersection of applied machine learning and security

My final-year project, targets agentic RAG pipelines, where an attacker can slip poisoned documents into the retrieval corpus or plant false memories through an ordinary-looking conversation, attacks that don't crash the system, they just make it confidently wrong. It translates three research frameworks, MEMSAD, RAGuard, and TrustRAG into one deployable layer that screens memory before it's trusted and filters poisoned documents during retrieval, without requiring the underlying model to change.

Alongside that, I'm a Research Assistant at SEECS, NUST, benchmarking how LLM-based vulnerability detectors hold up against traditional SAST tools once code has been obfuscated, and a Research Intern at Özyeğin University under Prof. Mesut Sayın, working on blockchain integration for adaptive vehicle routing (ARMG-CTOP). AegisVault, an ML-based web application firewall I built independently, runs live.
